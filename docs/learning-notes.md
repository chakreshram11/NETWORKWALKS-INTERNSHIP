## 🛠️ Command Reference

### Linux & Networking Basics
- `ifconfig` / `ip addr` - Display network interface details
- `ip route` - View current routing table
- `ping -c 4 <target>` - Verify network connectivity
- `netstat -tuln` / `ss -tuln` - Display active listening ports
